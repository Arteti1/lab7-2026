### **Відповідь на контрольне запитання:**

Для підрахунку та виведення статистики за кожним типом подій найзручніше використати клас `Counter` із вбудованого модуля `collections` (або звичайний словник `dict`). Під час обробки списку прочитаних записів ми витягуємо поле типу події (`item["event"]` або другий елемент після `line.split(",")`) і підраховуємо частоту кожного типу.

**Приклад реалізації у Python:**

```python
from collections import Counter

def print_event_statistics(events: list[dict[str, str]]) -> None:
    """Виводить кількість записів для кожного типу події у порядку спадання."""
    stats = Counter(item["event"] for item in events)

    print("Статистика по кожному типу подій:")
    for event_type, count in stats.most_common():
        print(f"  - {event_type}: {count}")
```

Метод `most_common()` автоматично сортує типи подій від найчастіших до найрідкісніших. Якщо потрібно також вивести відсоткову частку кожного типу події, достатньо поділити `count` на загальну кількість подій `len(events)` і відформатувати результат через f-рядок `f"{count / len(events) * 100:.1f}%"`.
